## 참고: 지난 세션에서 정한 것 한눈에

- 3D 실행 = ADG(속도가 다른 로봇이 칸 순서만 지킴). 재계획 = 지금 모습 = 새 0번 + 약속을 지키는 번호 다시 붙이기 → 코어 `replan()`/`full_replan()`.
- 안전 = 계획 검사(가) · ADG 순서(나) · 몸이 가진 칸 밖으로 안 나감(다, 칸 0.5 m + 돌고-가기). 결과는 몸 사각형 겹침·Gazebo 접촉·칸 이탈로 따로 검사.
- 실행 중 `plan()`을 부르지 않는다(PP는 처음 계획부터 실패할 수 있음) — `make_scenario`가 성공할 때까지 다시 뽑아 `initial_plan`에 저장.
- 화면은 RViz2 한 창, 녹화(`record:=`) → 다시 보기(`replay.launch.py` + `ros2 bag play`).
- 녹화 파일(`ros2/results/**/bag/`)은 git에 없음 — 이 컴퓨터에만 있다.
- 실제 로봇은 6대, 실험 바닥 크기는 아직 모름(사용자가 확인 후 알려 줌).
